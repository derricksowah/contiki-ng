# RPL Security Thesis Reproduction Guide

## Thesis Project

A Specification-Based Detection and Mitigation Framework for RPL Routing Attacks in Simulated IPv6 Wireless Sensor Networks.

The implementation uses Contiki-NG and Cooja and evaluates:

- Blackhole
- Grayhole
- Decreased Rank
- DODAG Version Number
- DIS Flooding

The project supports baseline, attack-only and mitigated simulation runs.
